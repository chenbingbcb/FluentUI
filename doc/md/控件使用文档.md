# 集成面板控件

## FluFormPane 表单面板控件
- 集成各类表单控件的面板控件, 以在线表单页面作为模板

### 属性说明
|属性|类型|必填|说明|
|----|----|----|----|
|formPaneData|json||表单面板数据, 含表单配置, 表单数据, 面板标题, 父对象等. 灵活配置统一入口, 以支持在FluTablePane或FluTreePane等控件上新建该表单窗口|

### 范例
```
FluFormPane {
    formPaneData: {
        formConfig: formConfig //表单配置
        , formData: rowFormData //表单数据
        , title: formTitle //面板标题
        , parent: tablePane //父对象, 如列表面板等
        , childTableCustomConfig: childTableCustomConfig
        , formDataSaveListener: formDataSave //保存表单数据监听器
    }
}
```

## FluTablePane 列表面板控件
- 集成列表, 列表操作按钮, 查询, 页码等的面板控件, 以在线表单页面作为模板, 各属性同时支持默认和自定义

### 属性说明
|属性|类型|必填|说明|
|----|----|----|----|
|tableConfig|json||列表配置|
|formConfig|json||表单配置|
|tableId|string||列表id, 用于在线表单|
|formId|string||表单id, 用于在线表单|
|menuId|string||菜单id, 用于在线表单|
|columnsUrl|string||获取列表配置url|
|formConfigUrl|string||获取表单配置url|
|listUrl|string||获取列表数据url|
|deleteUrl|string||删除单行数据url|
|addUrl|string||新增单行数据url|
|editUrl|string||更新单行数据url|
|queryByIdUrl|string||获取单行数据url|
|updateAllUrl|string||更新全部数据url|
|listCallback|function||获取列表数据回调|
|deleteCallback|function||删除单行数据回调|
|addCallback|function||新增单行数据回调|
|editCallback|function||更新单行数据回调|
|queryByIdCallback|function||获取单行数据回调|
|updateAllCallback|function||更新全部数据回调|
|relatedFields|string数组||关联字段|
|relatedRowData|json||关联行数据|
|tableTitle|string||列表控件标题|
|rowActionDelegate|Component||行操作委托组件|
|tableActionDelegate|Component||列表操作委托组件|
|formBelowDelegate|Component||表单下面委托组件|
|childTableCustomConfig|json||子表自定义配置|

### 范例
- tableConfig和formConfig由后端获取
```
FluTablePane {
    tableId: root.tableId
    formId: root.formId
    menuId: root.menuId
}
```
- tableConfig和formConfig由本地配置
```
FluTablePane {
        listUrl: "/sys/user/list"
        deleteUrl: "/sys/user/delete"
        addUrl: "/sys/user/add"
        editUrl: "/sys/user/edit"
        queryByIdUrl: "/sys/user/queryById"
        rowActionDelegate: comRowAction
        tableTitle: "用户管理"
        tableConfig: {...}
        formConfig: {...}
}
```
- 子表自定义配置
```
        FluTablePane {
            columnsUrl: "/online/genFormAPI/getColumns/1920671189235699714/0"
            formConfigUrl: "/online/genFormAPI/getFormConfig/1920759948459421697/0"
            listUrl: "/demo/testDemo2/list"
            deleteUrl: "/demo/testDemo2/deleteByParams"
            addUrl: "/demo/testDemo2/add"
            editUrl: "/demo/testDemo2/updateMainSub"
            queryByIdUrl: "/demo/testDemo2/queryByParams"
            updateAllUrl: "/demo/testDemo2/updateAll"
            childTableCustomConfig: [
                {
                    label: "子表1",
                    tableModel: "editAllModel",
                    columnsUrl: "/online/genFormAPI/getColumns/1920671189235622714/fb367426764077dcf94640c843733985",
                    listUrl: "/demo/testDemo2d1/list",
                },
                {
                    label: "子表2",
                    tableModel: "editAllModel",
                    columnsUrl: "/online/genFormAPI/getColumns/1920671189335622714/fb367426764077dcf94640c843733985",
                    listUrl: "/demo/testDemo2d2/list",
                }
```

# 其它

## onlineFormWindow 在线表单新建窗口
- 以在线表单页面作为模板的页面都可以新建该窗口对象, 可供其它自定义窗口参考
- 若嵌套多个新建窗口, 需根据每个页面情况适当考虑新建自定义窗口, 而非继续使用在线表单页面作为模板

### 范例
```
FluRouter.navigate("/onlineFormWindow", {
                        formPaneData: {
                            formConfig: formConfig
                            , formData: rowFormData
                            , title: formTitle
                            , parent: root
                            , childTableCustomConfig: childTableCustomConfig
                            , formBelowDelegate: formBelowDelegate
                        }
                    }, root)
```
